Practice

Practice is free and runs in your browser: same rules, nothing recorded, no credit spent.

Server verification

A paid run is played on SuperRare's server: the server keeps the clock, replays every move with the game's own rules and records the score. The page never sends a score.

Weekly prizes

One leaderboard per game, for the week: Friday 15:00 to Friday 15:00, Lisbon time. The first week runs from Thursday Oct 22, 00:00 to Friday Oct 30, 15:00. Prizes are handled by the organizer.

Purchase recovery

If credits you paid for don't show up, open the wallet, then "purchase help": it continues or claims an unfinished purchase. Never pay a second time for it.
